📌 日本語版

**Muscle Archive（以下「本アプリ」）**は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。

1. 収集する情報

本アプリでは、ユーザーの個人情報を収集しません。
入力されたトレーニング記録・データはすべてユーザーの端末内に保存され、開発者が閲覧することはありません。

2. 第三者への提供

取得した個人情報が存在しないため、第三者への提供は行いません。

3. 利用する外部サービス

今後のアップデートにて以下のサービスを導入する場合があります：

Google AdMob（広告配信）

Google Play Billing（アプリ内課金）

これらのサービスにより、広告識別子などの情報が収集される場合があります。
各サービスのデータ使用ポリシーについては以下をご確認ください：

Google プライバシーポリシー：https://policies.google.com/privacy

4. 未成年の利用

本アプリは全年齢を対象としており、未成年の利用も可能です。

2. Sharing of Information

3. Third-party Services

Future updates of the App may include the following services:

Google AdMob (advertising)

For details on how each service handles data, please refer to:

The App is available to users of all ages, including minors.
